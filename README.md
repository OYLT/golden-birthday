# Golden Birthday 🎂

金色粒子生日互动网页，使用 Three.js 和 MediaPipe 手部识别制作。单文件项目，无需 npm 安装或构建。

## 功能

- 金色粒子场景、生日蛋糕与彩带特效
- 摄像头手势互动、照片展示和信件展示
- 自定义生日标题、上传照片及背景音乐
- 导入 / 导出 JSON 配置
- 全屏展示

## 下载与运行

1. 点击仓库页面的 **Code → Download ZIP**，解压文件。
2. 在项目目录打开终端，运行以下命令（需已安装 Python）：

   ```bash
   python -m http.server 8000
   ```

   Windows 也可以使用：

   ```powershell
   py -m http.server 8000
   ```

3. 在同一台电脑的 Chrome 或 Edge 浏览器打开 **http://localhost:8000**。
4. 如需手势互动，请允许网页使用摄像头。

也可以使用 VS Code 的 Live Server 扩展启动。通过网络部署时请使用 HTTPS；摄像头通常要求 HTTPS 或 localhost。

## 使用方法

- **上传照片**：选择要在场景中显示的照片。
- **背景音乐**：选择本地音频。
- **书写信件**：编辑并保存祝福。
- **设置标题**：修改页面生日祝福。
- **导出配置**：下载包含当前标题、照片、音乐及信件的 JSON 配置。
- **导入配置**：选择此前导出的 JSON 恢复场景。
- **全屏显示**：进入全屏；全屏时控制按钮与摄像头预览会隐藏，可按 Esc 退出。

## 手势

对着摄像头做手势即可触发互动。识别结果显示在页面底部，实际效果受光线、距离和设备性能影响。

## 技术与依赖

- Three.js 0.160.0
- MediaPipe Tasks Vision 0.10.3
- Google Fonts

依赖、字体、手部识别模型及光晕贴图通过外部网络加载，因此运行时需要联网。照片、音乐和信件通过浏览器读取，项目没有自建上传后端；导出的配置包含你选择的媒体和信件，分享配置前请检查内容。
