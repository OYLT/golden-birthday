# Golden Birthday 🎂

金色粒子生日互动网页，使用 Three.js 和 MediaPipe 手部识别制作。单文件项目，无需 npm 安装或构建。

## 功能

- 金色粒子场景、生日蛋糕与彩带特效
- 摄像头手势互动、照片展示和信件展示
- 自定义生日标题、上传照片及背景音乐
- 导入 / 导出 JSON 配置
- 全屏展示

## 下载与运行

1. 点击仓库页面的 **Code → Download ZIP**，解压文件。
2. 在项目目录打开终端，运行以下命令（需已安装 Python）：

   ```bash
   python -m http.server 8000
   ```

   Windows 也可以使用：

   ```powershell
   py -m http.server 8000
   ```

3. 在同一台电脑的 Chrome 或 Edge 浏览器打开 **http://localhost:8000**。
4. 如需手势互动，请允许网页使用摄像头。

也可以使用 VS Code 的 Live Server 扩展启动。通过网络部署时请使用 HTTPS；摄像头通常要求 HTTPS 或 localhost。

## 使用方法

- **上传照片**：选择要在场景中显示的照片。
- **背景音乐**：选择本地音频。
- **书写信件**：编辑并保存祝福。
- **设置标题**：修改页面生日祝福。
- **导出配置**：下载包含当前标题、照片、音乐及信件的 JSON 配置。
- **导入配置**：选择此前导出的 JSON 恢复场景。
- **全屏显示**：进入全屏；全屏时控制按钮与摄像头预览会隐藏，可按 Esc 退出。

## 手势交互说明

先允许浏览器使用摄像头，将**一只手完整放入画面**，在光线充足的环境中操作。右下角会显示手部识别预览，底部会提示当前识别到的手势。

| 手势 | 怎么做 | 页面效果 / 使用条件 |
| --- | --- | --- |
| 三指「3」 | 伸出食指、中指、无名指，收起小拇指 | 粒子组成数字 **3** |
| 两指「2」✌️ | 伸出食指、中指，收起无名指、小拇指 | 粒子组成数字 **2** |
| 单指「1」☝️ | 只伸出食指，并让食指大致竖直 | 粒子组成数字 **1**；横向伸出的食指不触发这个效果 |
| 握拳 ✊ | 收起食指、中指、无名指和小拇指 | 显示生日蛋糕、生日标题，并触发彩带；持续握拳时彩带最多每隔约 2 秒触发一次 |
| 张开手掌 🖐️ | 伸展食指、中指、无名指和小拇指 | 粒子散开；移动手掌控制旋转，前后移动可调节散开程度 |
| 横向手枪手势 👉 | 伸出拇指和食指，收起其余三指，食指大致横向 | 聚焦并放大**离相机最近的一张照片**；需先上传照片 |
| Shaka /「🤙」 | 伸出拇指和小拇指，收起食指、中指、无名指 | 打开祝福信件并逐字显示；需先点击「书写信件」填写并保存内容 |

### 推荐体验顺序

1. 上传照片、选择背景音乐，填写祝福信件，并设置标题。
2. 依次做出 **3 → 2 → 1 → 握拳**，展示倒计时数字和生日蛋糕。
3. 张开手掌散开粒子，再用横向手枪手势聚焦照片。
4. 做出 **🤙** 手势打开信件，点击信纸右上角 **×** 关闭。

### 交互细节

- **倒计时由手势逐个控制**，不是显示「3」后自动倒数；也可以直接握拳显示蛋糕。
- 照片手势会自动选择离场景相机最近的照片，不是通过食指指向来选择照片。
- 信件打开后，其他手势暂不响应，手离开画面也不会自动关信；请点击 **×** 退出。
- 蛋糕显示后，普通聚合状态会继续保留蛋糕形态。
- 识别结果可能受光线、手与摄像头的距离和遮挡影响；切换手势时可稍作停留。
- 全屏模式会隐藏控制按钮、手部预览和手势提示。电脑可按 **Esc** 退出全屏。

## 技术与依赖

- Three.js 0.160.0
- MediaPipe Tasks Vision 0.10.3
- Google Fonts

依赖、字体、手部识别模型及光晕贴图通过外部网络加载，因此运行时需要联网。照片、音乐和信件通过浏览器读取，项目没有自建上传后端；导出的配置包含你选择的媒体和信件，分享配置前请检查内容。
